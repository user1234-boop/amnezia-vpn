# Личный VPN на AmneziaWG

Свой VPN на сервере в Нидерландах, без Telegram-бота и без российского сервера.
Основано на опыте [MOST-](https://github.com/aspentiv45-star/MOST-): та же маскировка AmneziaWG,
MTU 1280 и режим «только заблокированное» (~100 сетей).

```
Телефон (AmneziaWG) ──► Сервер NL ──► Telegram, YouTube, Instagram, X, Discord, сайты на Cloudflare…
        └──────────────────────────► банки, Госуслуги, Ozon, VK — напрямую, как без VPN
```

- **Порт** — случайный 1024–9999 (не 443 и не стандартные порты VPN), плюс два резервных.
- **MTU 1280** у сервера и клиентов + ограничение TCP MSS 1240: на мобильном интернете сайты не зависают.
- **Режим «обход»** (по умолчанию для телефона): через VPN идут только заблокированные сервисы — 99 сетей
  (лимит 100: больше приложения Amnezia обрабатывают плохо). Российские сайты работают напрямую.
- **Режим «весь трафик»** (для компьютера): всё через Нидерланды.
- **Сторож** раз в минуту проверяет сервер и сам чинит, если что-то пошло не так.
- На каждое устройство — **3 конфига** (основной и 2 резервных с другими портами и маскировкой).

---

## 1. Подключиться к серверу через Termius

1. Поставьте **Termius** (App Store / Google Play / termius.com для компьютера).
2. **Hosts → + → New Host**:
   - **Address**: `199.246.126.40`
   - **Port**: `22`
   - **Username**: `root`
   - **Password**: пароль от сервера из письма / панели 62yun
3. Сохраните и нажмите на хост — откроется терминал. На вопрос про fingerprint ответьте **Continue/Yes**.

> Не подключается — проверьте в панели 62yun, что сервер запущен и на нём **Ubuntu 22.04 или 24.04**
> (если стоит другая ОС — переустановите на Ubuntu 24.04 в панели).

**Вход по ключу вместо пароля (рекомендуется):** Termius → **Keychain → + → Generate Key** (тип ED25519),
затем в настройках хоста выберите этот ключ и нажмите **Export to host** — Termius сам положит ключ на сервер.

## 2. Установить VPN

В терминале Termius вставьте по очереди:

```bash
apt update && apt install -y git
```

```bash
git clone https://github.com/user1234-boop/amnezia-vpn.git && cd amnezia-vpn
```

```bash
bash install.sh
```

Установка идёт 2–5 минут (собирается модуль ядра). В конце скрипт покажет порты и созданные устройства:
`iphone` (режим «обход») и `pc` (весь трафик).

Другие устройства сразу при установке: `bash install.sh --devices "iphone android mama pc:full"`.
Свой основной порт: `bash install.sh --port 7385` (1024–9999, не 443).

> **Файрвол хостинга.** Если в панели 62yun есть firewall / security group — откройте там три UDP-порта,
> которые назвал скрипт (их всегда можно посмотреть: `vpn status`).

## 3. Подключить телефон

1. Поставьте приложение **AmneziaWG** (iPhone: App Store; Android: Google Play).
   Для компьютера — **AmneziaWG** для Windows/macOS или **AmneziaVPN**.
2. Получите конфиг одним из способов:
   - **QR-код:** в Termius наберите `vpn qr iphone`, в AmneziaWG — **+ → Сканировать QR-код**.
     Конфиг «обхода» длинный (99 сетей), QR большой — уменьшите шрифт в Termius (щипок) или используйте файл.
   - **Файл (надёжнее):** в Termius откройте **SFTP**, зайдите в `/root/vpn-configs/iphone/`, скачайте
     `iphone-1.conf`, `iphone-2.conf`, `iphone-3.conf` и откройте их в AmneziaWG (**Поделиться → AmneziaWG**
     или в приложении **+ → Импорт из файла**). Там же лежат PNG с QR-кодами.
3. Включите туннель `iphone-1`.

### Три туннеля на устройство

| Туннель | Порт | Чем отличается |
|---|---|---|
| `имя-1` | основной | обычная маскировка |
| `имя-2` | резерв 1 | другой порт и другие пакеты-пустышки |
| `имя-3` | резерв 2 | другой порт и маскировка под ответ DNS (`I1`) |

Ключ у всех трёх один — **включайте только один туннель за раз**. Если `-1` перестал работать
(например, оператор начал резать этот порт), просто включите `-2` или `-3` — ничего переустанавливать не надо.
Импортируйте все три сразу, чтобы резерв всегда был под рукой.

## 4. Что происходит автоматически

**Сторож** (`vpn-watchdog`, раз в минуту, журнал `/var/log/vpn-watchdog.log`):

| Что сломалось | Что делает сторож |
|---|---|
| После обновления ядра не грузится модуль AmneziaWG | ставит заголовки ядра, пересобирает модуль, загружает |
| Упал VPN или слушает не тот порт | перезапускает; после 3 неудач пересоздаёт конфиг сервера из сохранённых настроек |
| Пропали правила iptables (NAT, резервные порты, MSS) | ставит заново |
| Выключилась пересылка пакетов | включает |
| Сменился сетевой интерфейс | переписывает NAT |
| Сменился внешний IP сервера | пересобирает все конфиги устройств под новый IP (их нужно заново импортировать) |
| У сервера пропал интернет | пишет в журнал (это проблема хостинга) |

**Честно о пределах:** приложение AmneziaWG на телефоне не умеет само скачивать новые конфиги — для этого
у друга и сделан бот. Поэтому без бота «автоматическая смена» устроена так: сервер сам себя чинит,
а на телефоне заранее лежат 3 разных туннеля, и переключиться на рабочий — одно касание.
Если заблокируют все три — `vpn rotate` (см. ниже) и импорт новых файлов.

## 5. Если VPN не работает

1. Переключитесь на туннель `-2`, потом `-3`.
2. В Termius: `vpn status` — всё ли ✅. В строках портов видно, сколько пакетов пришло на каждый порт:
   включите туннель на телефоне и повторите `vpn status` — если счётчик порта **не растёт**, пакеты
   с телефона до сервера не доходят (режет оператор) → используйте другой туннель или смените порты.
3. Сменить порты: `vpn rotate --ports` · сменить маскировку: `vpn rotate --obfs` · всё сразу: `vpn rotate`.
   После этого **старые конфиги не работают**: импортируйте новые из `/root/vpn-configs/`.
4. Если не проходит вообще ничего (и Termius тоже не подключается из России) — скорее всего заблокировали
   IP сервера. Возьмите новый IP в панели 62yun: сторож сам пересоберёт конфиги в течение 10 минут
   (или сразу: `cd amnezia-vpn && bash install.sh`).

## Telegram-бот (по желанию)

Админ (вы) управляет VPN из Telegram и выдаёт доступ друзьям. Остальные могут только попросить VPN
и получить **свои** конфиги после вашего одобрения. Админские кнопки другим недоступны.

1. В Telegram: **@BotFather** → `/newbot` → придумайте имя → скопируйте **токен** (вида `123456:ABC...`).
2. На сервере (вместо `@dyssanu` — ваш ник; можно и числовой ID из @userinfobot):
   ```bash
   cd ~/amnezia-vpn && git pull && bash bot.sh 'ТОКЕН' @dyssanu
   ```
3. **Сразу** откройте бота и нажмите `/start`: первый `/start` от этого ника закрепляет ваш числовой
   Telegram ID как админа. Дальше права привязаны к ID — смена ника их никому не передаст.

**Для других людей:** `/start` → **🙏 Попросить VPN**. Вам приходит заявка с кнопками
**✅ Обход** / **✅ Весь трафик** / **❌ Отказать** / **🚫 Заблокировать**. После одобрения на сервере
создаётся отдельное устройство (по нику человека), и ему приходят 3 конфига с инструкцией. Потом у него
есть кнопки **📄 Мои конфиги**, **❓ Как подключить** и **🙏 Попросить ещё конфиг** (тоже через одобрение).

**Для вас:**
- **📱 Устройства** — все устройства (видно, чьё), файлы, QR 1/2/3, смена режима, удаление
  (человеку придёт «доступ отключён»).
- **🙋 Заявки** — ожидающие заявки (новые приходят сразу).
- **➕ Добавить** — устройство для себя.
- **👥 Люди** — кому выдан доступ, кто заблокирован (и разблокировка).
- **📊 Статус** — то же, что `vpn status`.
- **🔄 Сменить порты** — порты, маскировку или всё; новые конфиги бот рассылает сам:
  вам — все, каждому человеку — его.

Автоматически: сторож пишет вам обо всём, что починил; после смены портов (в том числе `vpn rotate`
из терминала) или IP сервера бот сам рассылает новые конфиги всем.

Выключить бота: `bash bot.sh off`. Логи: `journalctl -u vpn-bot -f`.
Люди и их устройства: `/etc/vpn/bot-users.json`.

## Команды

```
vpn add ИМЯ           новое устройство, режим «обход» (через VPN только заблокированное)
vpn add ИМЯ --full    новое устройство, весь трафик через VPN (компьютер)
vpn list              устройства: подключены ли сейчас, трафик
vpn qr ИМЯ [1|2|3]    QR-код конфига в терминале
vpn show ИМЯ [1|2|3]  текст конфига
vpn mode ИМЯ split|full   сменить режим устройства
vpn del ИМЯ           удалить устройство
vpn status            здоровье сервера и порты
vpn rotate [--ports|--obfs]   новые порты и/или маскировка
vpn set-ports 7385 [Р1 Р2]    задать порты вручную (1024–9999, не 443)
vpn nets [-v]         сколько сетей в режиме «обход» (и список)
vpn regen             пересобрать конфиги (после правки списка сетей)
```

## Список заблокированных сетей

- Основной список — [`lib/blocked-nets.txt`](lib/blocked-nets.txt) (на сервере `/etc/vpn/blocked-nets.txt`):
  Telegram, WhatsApp/Instagram/Facebook, YouTube/Google, X, Discord, Twitch, Reddit (Fastly), TikTok,
  Cloudflare (ChatGPT, rutracker и тысячи сайтов), DNS 1.1.1.1. DNS тоже идёт через VPN — иначе
  российский DNS отдаст YouTube «российские» адреса и видео пойдёт мимо VPN.
- Свои сети — `/etc/vpn/extra-nets.txt` (по одной на строку), затем `vpn regen` и импорт конфигов заново.
- Всего не больше 100: `vpn regen` откажется собирать конфиги, если сетей больше.

## Обслуживание

```bash
cd amnezia-vpn && git pull && bash install.sh   # обновить скрипты, ключи и устройства сохраняются
tail -f /var/log/vpn-watchdog.log               # журнал сторожа
awg show                                        # подключения AmneziaWG
bash uninstall.sh                               # удалить (с резервной копией в /root)
```

Где что лежит на сервере: настройки и ключи — `/etc/vpn/`, конфиг AmneziaWG — `/etc/amnezia/amneziawg/awg0.conf`,
конфиги устройств — `/root/vpn-configs/`. В репозиторий ничего из этого не попадает.

Клиентам VPN закрыты торренты и исходящий порт 25 (спам) — главные причины жалоб хостинга в Нидерландах.
Разрешить торренты: `echo BLOCK_TORRENTS=0 >> /etc/vpn/options && vpn-rules up`.
